# 喂奶统计支持「亲喂/瓶喂」切换 + 新增「主要喂养方式」设置

## 设计结论（已与你确认）
- **管理页** `/[name]/manage` 的「宝宝资料」卡新增 **主要喂养方式**（亲喂/瓶喂），仿照性别字段，作为统计页的默认视图。
- **统计页** 喂奶指标下方增加 **亲喂/瓶喂 小切换开关**（Chip），可临时切到另一种查看；初始值取自设置。
- **亲喂趋势图** Y 轴 = **每日次数**；时长、侧别等放明细区。
- 瓶喂视图沿用现有展示（日均奶量/总奶量/次数/单次均/最大），趋势图 Y 轴不变（每日 ml）。

## 一、后端：扩展亲喂聚合数据

### 1. `server/schema.ts`
- 新增枚举：`feedingMethods = ["breast", "bottle"] as const` + `FeedingMethod` 类型（复用既有 bottle/breast 词汇，与 `FeedDetails.method` 一致）。
- `babies` 表新增列：`feedingMethod: text("feeding_method", { enum: feedingMethods })`（可空，仿照 `gender`）。

### 2. `server/inputs.ts`
- `createBabySchema` 加 `feedingMethod: z.enum(["bottle", "breast"]).optional()`；`updateBabySchema = .partial()` 自动带上。

### 3. `server/routes/babies.ts`
- POST `/` insert 加 `feedingMethod: body.feedingMethod ?? null`。PATCH 是泛型无需改。

### 4. `server/routes/stats.ts` — 扩展 `BucketAgg`
当前亲喂只有 `breastMinutes`。新增字段：
```ts
breastMinutes, breastCount, breastMax,  // 总分钟、次数、单次最大分钟
breastLeftCount, breastRightCount, breastBothCount,  // 侧别次数
daysWithData: { bottle; diaper; pump; sleep; breast }  // 加 breast
```
改动点：
- `BucketAgg` 类型（~line 73-98）
- `/trend` 累加器初始化（~367-390）：加 `breastCount/breastMax/breastLeftCount/.../daysBreast`
- `/trend` 聚合循环 feed 分支（~411-413）：按 `d.side` 累加，`daysBreast.add(dayIdx)`
- `/trend` 输出 map（~441-465）：吐出新字段
- `/summary`（~283-311）同步给亲喂加 count/max（瓶喂已用 `bottle: number[]`，亲喂平行用 `breast: number[]`），返回 `Summary.breast` 结构体（或扩展现有）。**注意：summary 当前未被统计页消费**，仅为 API 完整性，可最小改动或暂不动 —— 决定：**暂不改 `/summary`**，统计页只用 `/trend`。

### 5. 数据库迁移
- `pnpm db:generate` 生成 `drizzle/0004_*.sql`（一条 `ALTER TABLE babies ADD feeding_method text;`）。
- 不在此计划内执行 `migrate:remote`；本地 `db:migrate:local` 验证。

## 三、前端：统计页亲喂/瓶喂切换视图

### 10. `components/stats/metrics.ts`
- `Metric` 不变（仍是顶层 4 选 1），新增并行的「喂奶方式」概念。新增一个 `FeedMethod` 类型 = `"bottle" | "breast"`。
- 新增 `dailyAvgFeed(method, agg)` 与 `daysRecordedFeed(method, agg)`，返回对应方式的数据：
  - `breast`：日均次数 = `breastCount / daysWithData.breast`；`daysRecorded` = `daysWithData.breast`
  - `bottle`：日均 ml = `bottleMl / daysWithData.bottle`（= 现有逻辑）
- 新增 `feedMethodMeta(method)`：返回 `{ emoji, label, accent: "rose", format }`，亲喂用 `formatMinutes`、瓶喂用 `formatMl`。

### 11. `components/stats/metric-detail.tsx`
`MetricDetail` 加一个可选 `feedMethod?: FeedMethod` prop（仅 metric==="feed" 时有意义）：
- `feedMethod === "breast"` → 渲染亲喂网格：
  - `日均次数` = breastCount / daysWithData.breast
  - `总次数` = breastCount
  - `总时长` = formatMinutes(breastMinutes)
  - `单次均` = breastMinutes / breastCount（formatMinutes）
  - `最长单次` = formatMinutes(breastMax)
  - `侧别分布`：三栏小卡 左侧 X 次 / 右侧 X 次 / 双侧 X 次（breastLeftCount/RightCount/BothCount）
- `feedMethod === "bottle"`（或 undefined 兼容） → 现有瓶喂网格（把现在的「亲喂」汇总格去掉，因为已在切换视图里单独展示）。

### 12. `app/[name]/stats/page.tsx`
- 新增 state `feedMethod: FeedMethod`，初始值 `baby.feedingMethod ?? "breast"`（取自设置；用 `useMemo`/初始化函数，避免每次渲染覆盖）。注意 `baby` 加载前可能为空，需在 `baby` 就绪后初始化 —— 用 `useState` + 在 baby 就绪分支里做一次性校正，或用受控默认：直接在渲染时以 `feedMethod` state 为准，初始 `"breast"`，baby 加载完后用 `useEffect` 同步一次（带「仅同步一次」标志）。
- **仅在 `metric === "feed"` 时**，在指标行下方渲染 亲喂/瓶喂 Chip 切换（rose accent）。
- 趋势图 `bars` 的 `value`：当 `metric==="feed"` 用 `dailyAvgFeed(feedMethod, agg)`，否则沿用 `dailyAvg(metric, agg)`。
- 标题 `🍼 喂奶量趋势` → 根据 feedMethod 动态：亲喂「🤱 亲喂次数趋势」、瓶喂「🍼 喂奶量趋势」；caption 的 format 同理（亲喂展示「日均 X 次」、瓶喂展示「日均 xml」）。
- 明细 `<MetricDetail>` 传入 `feedMethod`。
- `useBaby()` 已能拿到 `baby.feedingMethod`。

### 13. 数据流与缓存
- 无需新增 SWR key；`/stats/trend` 返回的 `BucketAgg[]` 已含两种方式数据，切换只是前端切视图。
- pull-to-refresh 已覆盖 `trend:` 前缀，无需改。
