# 宝宝体重/身高测量记录 + 成长趋势图

## 设计概要

在现有「拾光记」基础上，新增**身体测量记录**（体重 + 身高）和**成长趋势折线图**。测量数据独立于现有的活动日志（baby_logs），用新建的 `baby_measurements` 表承载，语义干净、为后续头围等扩展留好结构。

### 交互架构（最终确认）

**① 仪表盘重构**（`app/[name]/page.tsx`）
```
TodayBanner           ← 保留
TodaySummary (4卡片)  ← 保留
「身体」区 (新增)     ← 显示当前体重/身高 + 测量时间 + [+ 记录] 按钮
ActionDock            ← 保留（喂养区 + 护理区）
（Timeline 移除）     ← 最近动态移到 history 页查看
```

**② 统计页顶部加 Tab 切换**（`app/[name]/stats/page.tsx`）
```
统计页
─────────────────────
[记录]  [成长]       ← 顶部 Tab，默认选中「记录」
─────────────────────
记录 Tab（第一个，默认）:
  现有喂奶/产奶/尿布/睡眠柱状趋势图，原样保留
  指标: [喂奶][产奶][尿布][睡眠]
  粒度: [日][周][月][季][年]
成长 Tab（第二个）:
  指标: [体重] [身高]
  粒度: [月] [季] [年]   ← 只看月/季/年
  ┌──────────────────┐
  │   折线图          │
  │   体重增长趋势    │
  └──────────────────┘
  最新: 8.2 kg · 8月3日
```

**③ 录入**：从仪表盘「身体」区或统计页成长 Tab 打开 `MeasurementDrawer`，数值步进 + 预设 + 时间，沿用 `pump-drawer.tsx` 的成熟范式。

## 实施步骤

### Step 1 — 数据层：新建 measurements 表

**`server/schema.ts`** 新增：
```ts
export const measurementKinds = ["weight", "height"] as const;
export type MeasurementKind = (typeof measurementKinds)[number];

export const babyMeasurements = sqliteTable("baby_measurements", {
  id: integer("id").primaryKey({ autoIncrement: true }),
  babyId: integer("baby_id", { mode: "number" }).notNull().references(() => babies.id),
  kind: text("kind", { enum: measurementKinds }).notNull(),
  measuredAt: integer("measured_at", { mode: "number" }).notNull(), // unix 秒
  valueGrams: integer("value_grams", { mode: "number" }).notNull(), // 体重存克、身高存毫米，统一整数
  notes: text("notes"),
  createdAt: integer("created_at", { mode: "number" }).notNull(),
});
```
- 体重存克（8200 = 8.2 kg），身高存毫米（680 = 68.0 cm）—— 零小数、无迁移、`amount` 列不受影响
- 字段名 `valueGrams` 沿用现有 camelCase 风格；身高虽然语义是毫米，但复用同一列避免拆表

运行 `pnpm db:generate` 生成 `drizzle/0002_*.sql` 迁移。

### Step 2 — 后端：Hono measurements 路由

**新建 `server/routes/measurements.ts`**（挂在 `server/app.ts`，与 logs/stats 平级）：
- `GET /api/measurements?babyId=&kind=` — 返回该宝宝某种类的全部测量（按时间升序），供趋势图与「当前值」展示
- `POST /api/measurements` — 新建 `{ babyId, kind, measuredAt, valueGrams, notes? }`
- `PATCH /api/measurements/:id` — 编辑
- `DELETE /api/measurements/:id` — 删除

**`server/inputs.ts`** 新增 `createMeasurementSchema` / `updateMeasurementSchema`（zod 校验，复用 `@hono/zod-validator`）。

**`server/app.ts`** 挂载 `.route("/measurements", measurementsRoutes)`。

### Step 3 — 前端数据层：SWR hooks + mutations

**`lib/hooks.ts`** 新增：
```ts
export const MEASUREMENTS_KEY = (babyId: number, kind: MeasurementKind) =>
  `measurements:${babyId}:${kind}`;
export function useMeasurements(babyId: number | null, kind: MeasurementKind) { ... }
```

**`lib/mutations.ts`** 新增 `createMeasurement` / `updateMeasurement` / `deleteMeasurement`，复用现有乐观更新 + toast + `mutate` 失效模式（失效 `measurements:{babyId}:*`）。

**`lib/types.ts`** re-export `MeasurementApi` 类型（type-only，避免服务端进客户端 bundle）。

**`lib/measure.ts`**（新建）— 纯函数工具：
- `formatWeight(grams)` → `"8.2 kg"`（照 `formatMl` 的模式）
- `formatHeight(mm)` → `"68.0 cm"`
- `gramsToKg` / `kgToGrams` / `mmToCm` / `cmToMm`

### Step 4 — 录入抽屉：MeasurementDrawer

**新建 `components/log-entry/measurement-drawer.tsx`**，复制 `pump-drawer.tsx` 骨架：
- 大数字显示 + ±步进 + 预设快捷值
  - 体重：步进 50g，预设 `[3000, 5000, 7000, 9000]`，单位 kg（输入框直接键入小数，内部换算成克）
  - 身高：步进 5mm，预设 `[500, 550, 600, 700]`，单位 cm
- `datetime-local` 时间 + 备注输入 + 主题色保存按钮
- 配色用 `pink`（体重）/ `cyan`（身高）—— 现有未占用的 Tailwind 语义色，避开喂奶/护理已有色

**`components/log-entry/log-entry-provider.tsx`**：
- `DrawerKind` 加 `"weight" | "height"`
- 暴露 `openWeight` / `openHeight`
- `Drawers` memo 组内挂载 `MeasurementDrawer`（用 `kind` 区分）

### Step 5 — 仪表盘身体记录区 + 去 Timeline

**新建 `components/dashboard/body-summary.tsx`**：
- 横向两卡片（体重 / 身高），显示「当前值 + 测量时间（relative）」
- 底部 `[+ 记录]` 按钮打开对应抽屉
- 数据来自 `useMeasurements(babyId, "weight")` 取最后一条；无数据时显示「暂无 · 点击记录」

**`app/[name]/page.tsx`** 改造：
```tsx
<TodayBanner />
<TodaySummary babyId={baby.id} />
<BodySummary babyId={baby.id} />   {/* 新增 */}
<ActionDock babyId={baby.id} />
{/* <Timeline /> 移除 */}
```
- 下拉刷新的 mutate key 前缀增加 `measurements:${baby.id}:`

### Step 6 — 成长折线图组件

**新建 `components/stats/growth-chart.tsx`**（纯 SVG + Tailwind，零依赖，与 `trend-chart.tsx` 同范式）：
- 输入 `points: { label: string; value: number | null; isCurrent: boolean }[]`
- SVG `<polyline>` 连线 + `<circle>` 数据点 + 选中点高亮 + 顶部数值
- 选中/无数据的交互与 `TrendChart` 完全一致（selectedIndex、aria-label）
- 复用 `ACCENT_TEXT` / 新增 `ACCENT_LINE` 线色（pink/cyan），深浅双模式

### Step 7 — 统计页：顶部 Tab + 成长视图

**`app/[name]/stats/page.tsx`** 改造：
- 顶部新增 Tab 切换，**第一个「记录」（默认）、第二个「成长」**（用 shadcn `Tabs` 或现有 Chip 模式）
- **记录 Tab**（第一个、默认）：现有 4 指标柱状图逻辑原样保留
- **成长 Tab**（第二个，新增）：
  - 指标 Chip：体重 / 身高
  - 粒度只保留 月 / 季 / 年（按你的要求，去掉日/周）
  - 调用 `useMeasurements`，前端按所选粒度把测量值聚合到周期（取该周期**最后一条**测量值作为该周期代表值，符合「快照」语义）
  - 渲染 `<GrowthChart>` + 选中周期明细卡（显示该周期首末测量值 + 变化量）
- 切到「成长」Tab 时，下拉刷新 mutate key 也覆盖 `measurements:${baby.id}:`

### Step 8 — 命名与文案

- 体重 emoji `⚖️`，身高 emoji `📏`
- 文案沿用全中文风格：「记录体重」「记录身高」「体重增长」「身高增长」

## 不做的事
- ❌ 不引入任何图表库（沿用 div/SVG + Tailwind 手写范式）
- ❌ 不改 `baby_logs` 表结构 / `activityTypes` 枚举（测量数据完全隔离）
- ❌ 不加 i18n / 单位切换（全中文、kg + cm）
- ❌ 不碰 history 页的测量记录展示（测量走独立表，历史页仍只看活动日志；若需要后续可加）
- ❌ 体重/身高趋势不看「日 / 周」粒度（数据稀疏无意义）
